# Network Overview (fictional example)

## Layout
Internet -> Router/Firewall -> Switch -> Office devices and Wi-Fi access point

## Network segments
| Segment | Purpose | Example address range |
|---|---|---|
| Office LAN | Staff computers and printers | 192.168.1.0/24 |
| Guest Wi-Fi | Visitors, kept separate from the office LAN | 192.168.10.0/24 |

## Main devices
| Device | Role |
|---|---|
| Router/firewall | Connects to the internet and blocks unwanted traffic |
| Switch | Connects wired devices |
| Wireless access point | Provides Wi-Fi |
| File server or NAS | Shared files and backups |

## Key principle
Keep guests and unknown devices separate from the systems that hold business data.
