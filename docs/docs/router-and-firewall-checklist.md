# Router and Firewall Checklist

- [ ] Default admin username and password changed
- [ ] Admin password is long and unique (15 or more characters)
- [ ] Remote administration from the internet is turned off
- [ ] Router firmware is up to date
- [ ] Firewall blocks unsolicited incoming connections by default
- [ ] Unused ports and services are disabled
- [ ] Logging is turned on and reviewed regularly
- [ ] Router configuration is backed up in a safe place
