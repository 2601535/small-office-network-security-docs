# Common Network Threats and Defences

| Threat | What it is | Main defences |
|---|---|---|
| Unauthorised access | Someone connects without permission | Strong Wi-Fi password, MFA, guest network |
| Malware | Harmful software spreading across the network | Updates, antivirus, restricted downloads |
| Phishing | Fake messages that steal logins | Staff awareness, email filtering, MFA |
| Eavesdropping | Capturing traffic on weak or open Wi-Fi | WPA3 or WPA2, VPN for remote work |
| Denial of service | Overloading a network so it stops working | Firewall rules, upstream protection from the internet provider |

## Layered defence
No single control is enough. Combine a firewall, updates, strong passwords, staff training and regular backups.
