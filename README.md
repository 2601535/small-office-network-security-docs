# Small Office Network Security Documentation

Basic, easy-to-follow documentation for securing the network of a small office.

## Contents
- `docs/network-overview.md`: a fictional example network and its parts
- `docs/router-and-firewall-checklist.md`: settings to check on the router and firewall
- `docs/wifi-security.md`: how to secure the wireless network
- `docs/common-threats-and-defences.md`: common network threats and how to reduce them

## Who is it for?
Small business owners, junior IT staff and students learning the basics of network security.

## Note
The network described here is fictional. This repository contains no real passwords, IP addresses in use or other sensitive details.
